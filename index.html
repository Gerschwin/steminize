      Split any song into stems

      Vocals, drums, bass and the rest, using Meta's Demucs model. Everything runs on this device; your audio is never uploaded.

      1. Add songs on the left. You can queue several.
      2. Pick a model. The first run downloads it once (136–664 MB), then it works offline.
      3. Play, loop and practise. Mute or solo stems, slow down, change key, then export.

      Speed depends heavily on your hardware: a recent GPU is much faster than CPU only. Try one song first to see how long yours takes.

      Models

      Models are stored in this browser/app and reused offline. If downloads are blocked on your network, fetch the files from Hugging Face yourself and import them here (the file names must match).

      From YouTube

      Downloads run locally via yt-dlp, straight into the import queue. You're responsible for having the right to use anything you download.
